# 資料模型與心智圖對應

## 內嵌 JSON（index.html 中的 `<script type="application/json" id="glossary-data">`）
```json
{"cats":["通用名詞", "..."],
 "data":[{"id":"t-001","n":"名詞","a":["別名"],"c":"分類","g":"群組標籤","s":"簡述","d":"・完整說明\n　・縮排","sec":"區塊(選填)"}]}
```
- 前端載入時驗證每筆資料（需有 id、n、s，且 c 在 cats 內）；無效資料略過並 `console.warn`。
- `d` 為空字串＝不可展開。
- `sec` 只在汽車險／機車險／商品專區使用。

## data.csv 欄位
`id, 分類, 區塊, 群組標籤, 名詞, 別名, 簡述, 完整說明`（UTF-8 BOM；別名用「、」或「,」分隔）。
目前共 123 筆：通用名詞 25、汽車險 24、機車險 17、旅平險 9、健康傷害險 1、責任險 9、住火險 5、商業火險 7、工程水險 2、商品專區 24。

## 心智圖 → 卡片的轉換規則（首次轉出時使用）
- 一個節點＝一張卡片（葉節點視情況併入父卡片的展開內容）。
- 節點文字 `名詞：說明` → 卡片標題＝名詞、簡述＝說明。
- 括號暱稱，如「（搗蛋險）」→ 別名。
- 子節點（例、理賠對象、理賠項目、承保範圍、自負額、啟動時間點、投保限制、保障範圍、加值選、承保對象…）→ 展開內容，每行以「・」開頭，層級以全形空白縮排。
- 小標籤（群組標籤）＝節點在心智圖中的所屬群組（如「契約角色」「責任險與超額險」），之後由使用者逐項改名（見 DECISIONS.md）。
- 「名詞解釋 → 個人保險 / 企業保險 / 通用名詞」對應分類；「常見投保專案商品」整支對應「商品專區」。
- 車體損失險的重複子節點（心智圖畫面上重複）已去重；個別險種（01 甲式、05 乙式、09 丙式、0H）獨立成卡。

## 群組標籤規則（使用者指定的覆寫）

## 資料維護注意
- `data.csv` 已包含使用者所有手動指定修改，是事實來源；不要用 xmind 重新轉出覆蓋。
- 新增卡片：在 CSV 加一列，`id` 留空，`python3 build.py`。
- 刪除卡片：直接刪列。已分享的 `#t-###` 連結會失效，請留意。
- 「@」已全部改為「歲」；簡述中的「＞」「＜」「＜＝」「＞＝」為車種排氣量／馬力的比較符號，保留。

# 決策與修改紀錄（依對話時序）

目的：讓新的 Claude Code 工作階段知道「為什麼現在長這樣」，避免把使用者已定案的事再推翻。

## 一、起始需求
- 做一個產險名詞搜尋網頁，版面參考「保險克勞斯」名詞百科截圖。
- 網站名稱：**產險懶人包**（最初寫「產險名詞懶人包」，後更正）。
- 標題：粗體黑字；風格：深藍主色、圓角卡片。
- 功能：即時搜尋（含別名與說明）、分類過濾、點卡片展開完整說明、手機版一欄。
- 交付：發布成網頁連結；資料與程式分開，方便之後新增名詞。
- 名詞資料以心智圖 `產險名詞大補帖.xmind` 為主。
